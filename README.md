# Modern Business Landing Page

A sleek, interactive, and fully responsive business landing page built with HTML, CSS, and JavaScript.

## Features

### 🎨 Modern Design
- **Gradient backgrounds** with beautiful color schemes
- **Glass morphism** effects and modern UI elements
- **Smooth animations** and micro-interactions
- **Professional typography** using Inter font
- **Clean layouts** with proper spacing and hierarchy

### 📱 Responsive Design
- **Mobile-first approach** with responsive breakpoints
- **Touch-friendly** navigation and interactions
- **Optimized layouts** for all screen sizes
- **Hamburger menu** for mobile devices

### ⚡ Interactive Features
- **Smooth scroll** navigation between sections
- **Animated counters** for statistics
- **Floating hero elements** with parallax effect
- **Auto-playing testimonial slider**
- **Interactive contact form** with validation
- **Hover effects** on service cards
- **Back to top** button with smooth scrolling

### 🎯 Sections Included
1. **Hero Section** - Eye-catching introduction with call-to-action
2. **Services** - Six comprehensive service offerings
3. **About** - Company features and technology stack
4. **Testimonials** - Client feedback with rotating slider
5. **Contact** - Contact form and company information
6. **Footer** - Links and additional information

### 🛠 Technologies Used
- **HTML5** - Semantic markup
- **CSS3** - Modern styling with Flexbox and Grid
- **JavaScript ES6+** - Interactive functionality
- **Font Awesome** - Icons
- **Google Fonts** - Typography
- **Intersection Observer API** - Scroll animations

## Quick Start

1. **Clone or download** the files
2. **Open index.html** in a web browser, or
3. **Run a local server**:
   ```bash
   python3 -m http.server 8000
   ```
   Then visit `http://localhost:8000`

## Customization

### Colors
The color scheme uses CSS custom properties and can be easily modified in the CSS file:
- Primary: `#6366f1` (Indigo)
- Secondary: `#8b5cf6` (Purple)
- Accent: `#ff6b6b` (Coral)
- Success: `#10b981` (Emerald)

### Content
All content can be customized in the HTML file:
- Company name and branding
- Service descriptions
- Contact information
- Testimonials
- Social media links

### Images
Replace the Unsplash placeholder images in testimonials with your own client photos.

## Performance Features

- **Optimized animations** with CSS transforms
- **Throttled scroll events** for better performance
- **Intersection Observer** for efficient scroll animations
- **Minimal dependencies** - only Font Awesome and Google Fonts
